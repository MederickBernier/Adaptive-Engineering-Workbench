# Project Brain

AEW's Project Brain stores revision-scoped knowledge for one checkout. Use the
[architecture](../../docs/architecture.md) and
[snapshot decision](../../docs/adr/ADR-003-revision-scoped-snapshots.md) when
changing assertion provenance, snapshot membership, or freshness.

Use the [Project Brain setup in the README](../../README.MD) to review and
publish initial knowledge for this checkout.
